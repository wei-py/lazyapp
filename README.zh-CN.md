# lazyapp

[English](README.md) · [中文](README.zh-CN.md)

一款纯本地、离线的 App 资料管理工具，同时提供 OpenTUI 终端界面与 Bun 本地 Web 编辑器，整理元数据、资源、平台凭据、服务、环境和商店资料。

没有云服务、遥测或数据库。两套界面共用 `<project>/.lazyapp/` 中的 JSON 配置与原始文件。

## 功能

### 一个工作台装下全部

你 App 的所有配置，都在一个可浏览的结构里：

| 分类         | 存放内容                                                                    |
| ------------ | --------------------------------------------------------------------------- |
| App          | 名称、描述、版本、启用的平台与环境                                          |
| Assets       | 图标、启动图、截图、宣传图、免责函、营业执照、软著、软著补充材料            |
| Platforms    | Android / iOS / HarmonyOS / Windows / macOS / 小程序 的身份与各环境签名凭据 |
| Services     | 第三方凭据（Apple、Google、华为、微信、地图、推送……）                       |
| Environments | 各环境的 API/Web/CDN 地址与变量                                             |
| Store        | 商店名称、文案、链接与图片                                                  |

环境按需创建、支持自定义名称——不强制每个平台都配 development/production。

### Prompt-first 初始化

首次启动在进入 raw mode／备用屏幕之前，先在普通终端询问：

```
No lazyapp workspace found. Create one? (y/N):
```

仅 `y`/`yes` 创建脚手架（沿用已保存语言）；空输入、`No` 或 EOF 都不写入并干净退出。回答 `y` 后直接进入 TUI，没有向导。

### 三面板工作台

窄左列（工作区信息、分类、列表）加右侧大详情面板，底部状态栏。60–99 列时折叠为单栏，小终端也不会撑破。

颜色承载含义：**红色** = 配置/资源缺失，**绿色** = 文件存在（只表示存在性，绝不表示凭据有效）。

### 字段级配置编辑

`Enter` 逐层进入：分类 → 列表 → 详情编辑器 → 字段。编辑干净草稿后，用 `s` 或详情末行的 `[ Save document ]` 保存。离开脏表单时始终提供 **保存 / 放弃 / 取消**；保存失败保留草稿；取消绝不写盘。

### 受管文件导入

缺失的资源（`source.png`、`certificate.p12`……）显示红色。`Enter` 一个缺失资源，确认源文件路径后即复制进工作区；也可只读引用外部文件。删除真实文件会保留其 `.example` 占位，条目依旧可见。

HarmonyOS 平台配置支持可选的 `material` 文件引用，通常为 `platforms/harmony/material.zip`。将已有 `material/` 目录压缩并保留该顶层目录，再通过文件字段导入。新工作区生成的是 `material.zip.example` 占位说明，不会伪造 ZIP 文件。材料包可能含敏感签名数据，请勿公开；导入与下载不会解压或校验包内内容。

### 只读 Doctor

一键检查字段完整性、引用存在性与配置一致性。严格区分「存在」与「有效」，凭据无法真正解析时报告「未检查」而非「通过」。

### `中文` / `English`

在 `Settings / 设置` 切换界面语言，保存后立即生效并跨启动持久化。

## 快速开始

```sh
# 安装
bun install

# TUI + Web：TUI 生命周期内同时启动本地 Web 服务
lazyapp tui /absolute/project
lazyapp tui /absolute/project --port 3210

# 仅 TUI（兼容原入口）
lazyapp /absolute/project

# 仅 Web，无需 TTY
lazyapp web /absolute/project --port 3210
```

源码运行时，以上 `lazyapp` 替换为 `bun src/main.js`。
无需实验性 FFI 参数。TUI 中按 `W` 也可启动默认端口 3210
的 Web 编辑器，地址显示在状态栏。退出 TUI 会同时关闭由该 TUI 启动的 Web 服务。
新项目可通过 TUI 启动询问创建工作区；仅 Web 不会自动创建工作区。

网页采用左侧分组导航、可展开的平台树与右侧共享编辑区；字段分组展示，保存栏保持可见，窄屏通过「导航」按钮展开清单。
默认进入「**总览**」：展示 App 信息、已有配置／工作区文件数量、启用平台和环境，以及各分类的存在／缺失清单；可直接编辑配置、查看文件或打开 Doctor。统计只读取磁盘快照，不计入未保存草稿，不自动运行诊断，也不把文件存在当作凭据有效。

仅使用本地 CSS／JavaScript，不依赖 CDN、外部字体；附件可导入、预览、下载、替换和删除。
外部绝对路径引用保持只读。TUI 与 Web 可以同时打开，每次写入独占加锁，
过期的配置／附件版本拒绝覆盖；发生冲突后显式重新加载。

已发布版本通过 mise 安装：

```sh
mise use -g github:wei-py/lazyapp@latest
lazyapp /absolute/project
```

## 使用

### 导航

| 按键                                             | 作用                                      |
| ------------------------------------------------ | ----------------------------------------- |
| `j`/`k`、`↓`/`↑`                                 | 在焦点面板内移动选择                      |
| `1`–`4` | 聚焦应用与资源、平台、服务/环境/商店、文件/Doctor |
| `0` | 聚焦右侧共享编辑区 |
| `Tab`/`Shift+Tab` | 在分组与详情间循环焦点，保留草稿 |
| `[`/`]` | 切换服务/环境/商店或文件/Doctor 页签 |
| `h`/`l`、`←`/`→` | 展开/收起平台树，或进入/离开详情 |
| `Enter` | 展开平台、打开条目、查看值；详情末行执行保存 |
| `Esc` | 取消输入/浮层，或从详情返回上次导航分组 |
| `?`                                              | 上下文帮助                                |

### 编辑与文件

| 按键 | 作用                 |
| ---- | -------------------- |
| `a`  | 新建配置             |
| `e`  | 编辑聚焦字段         |
| `f`  | 打开受管文件列表     |
| `D`  | 删除选中文件（确认） |
| `y`  | 复制聚焦字段的值     |
| `/`  | 路径搜索             |
| `s`  | 保存当前草稿         |
| `:`  | 设置（语言 / 主题）  |
| `L`  | 切换 中文 / English  |
| `q`  | 退出（有任务时 y/n） |

文本编辑状态下，`j`/`k`/`h`/`l`/`q`/`?`/`g`/`G`/`/` 均为普通字符——Vim 式导航只在文本输入之外生效。

默认主题为固定的 **Gruvbox Light** 不透明浅色配色，不随终端明暗检测变化。缺失偏好和旧的通用 `default` 值读取为新默认，读取时不改写设置；已有命名主题保持原选择。按 `:` 可选择其他主题，或显式选择「**自动（终端）**」（`auto`）跟随终端模式；无法检测时自动模式使用不透明深色。Gruvbox Light 的文字和文件状态颜色在面板与选中行上均保持清晰可读。

按 `?` 打开「**导航／操作／须知**」分类帮助，支持中英文。左右方向键或 `[`/`]` 切换分类，上下方向键与 `PgUp`/`PgDn` 滚动，`Esc`/`Enter` 关闭并恢复之前的焦点。各分类保留本次打开期间的滚动位置，快捷键和说明分列，窄窗口自动换行；安全与存储说明集中在须知中，不挤占快捷键列表。

### 典型流程

1. 运行 `lazyapp /path/to/project`，首次使用接受初始化。
2. 在 **App** 分类启用你需要的平台与环境。
3. 逐个浏览平台——缺失的配置/资源显示红色。`Enter` 红色配置进入干净草稿编辑后保存；`Enter` 红色资源导入文件。
4. 逐步补充第三方服务和各环境变量。
5. 运行 **Doctor** 找出缺失或不一致项。
6. `q` 退出；数据持久化在 `.lazyapp/`，TUI 与 Web 重开共用同一份资料。

## 数据与安全

- 允许本地明文保存密码、Token 和私钥，但这里**不是加密保险箱**。备份、同步工具、恶意进程和误提交仍可能泄漏数据。
- 敏感值在摘要、日志和 Doctor 中一律遮蔽；输入默认隐藏。
- POSIX 下新建数据目录使用 `0700`，配置/凭据/临时文件使用 `0600`；工作区内自动创建内容为 `*` 的 `.gitignore`。
- 保存采用临时文件替换、独占写锁和外部修改检测。损坏的 JSON 与不支持的 schemaVersion 绝不被覆盖。

## 文档与开发

| 命令                                                        | 用途                                             |
| ----------------------------------------------------------- | ------------------------------------------------ |
| `bun src/main.js tui /absolute/project`                    | 同时运行 TUI 与 Web                              |
| `bun run dev /absolute/project`                            | 仅运行 TUI；TUI 内按 `W` 可启动 Web              |
| `bun run web /absolute/project`                            | 仅启动本地 Web 服务，默认端口 3210               |
| `bun run lint` / `bun run lint:fix`                         | 通过 Bun 执行 ESLint 检查 / 修复                 |
| `bun test`                                                 | 使用 Bun 的 `node:test` 兼容层执行行为测试       |
| `bun run build`                                            | 构建当前平台 Bun 独立发行包及 SHA256SUMS         |
| `bun run smoke:source` / `bun run smoke:release`             | 仅本地通过真实 PTY 验证源码 / 解压后的发行包      |

- `docs/spec.md` — 权威开发契约（键盘、布局、存储、安全、验收）。
- `docs/lazyapp.md` — 产品构想与数据组织示例。

工具链固定为 Bun `1.4.2` 与 OpenTUI `0.5.11`；源码运行要求 Bun >=1.4.2，
无需实验性 FFI 参数。按仓库无锁文件约定，`bunfig.toml` 禁止写入锁文件。

发布工作流在对应 runner 构建 macOS（arm64/x86_64）、Linux（x86_64/arm64，
glibc）与 Windows（x86_64）。Bun 独立发行包内嵌运行时与 OpenTUI 原生资源，
本地 Web 资源位于可执行文件旁，用户无需另行安装 Bun 或 Node.js。
CI/CD 不执行任何冒烟测试；两个冒烟命令仅供本地运行。
实际验证范围与目标平台限制见 `docs/spec.md`。

# lazyapp 操作指南（用户视角）

> 本文面向使用者，说明你如何用 lazyapp 管理一个 App 的元数据、资源、平台配置、证书、服务、环境与商店资料。
> 全程键盘即可完成，鼠标只是辅助。所有数据保存在本地工作区目录，离线运行，不上传、不同步。

---

## 1. 首次启动

在终端里，进入你的项目目录后运行 `lazyapp`（或 `lazyapp /绝对路径/项目`，路径省略时使用当前目录）。

1. 程序先确认你正在交互式终端里运行；不是终端则直接报错退出，不会改动屏幕。
2. 如果你要管理的项目还没有 `lazyapp` 数据目录，屏幕会显示一行普通询问：

   ```
   No lazyapp workspace found. Create one? (y/N):
   ```

   - 输入 `y`（或 `yes`，不分大小写）→ 自动创建最小工作区并**直接进入主界面**，没有多余向导。
   - 直接回车、输入其他内容、或按 Ctrl+D → 什么都不创建，正常退出。
   - 按 Ctrl+C → 退出（退出码 130）。

3. 如果工作区已经存在，跳过询问，直接进入主界面。
4. 进入主界面后，底部状态栏提示：本地文件是明文保存、界面里做了遮蔽，但这不是加密保险箱。

---

## 2. 主界面布局

主界面由三个可聚焦的面板组成，左侧纵向堆叠「工作区信息 → 分类 → 列表」，右侧是「详情」和下方状态栏，最底行显示当前可用的快捷键。

| 编号 | 面板 | 你在这里做什么                                                                                |
| ---- | ---- | --------------------------------------------------------------------------------------------- |
| `1`  | 分类 | 选择要管理的内容类型：App、Assets、Platforms、Services、Environments、Store、Doctor、Settings |
| `2`  | 列表 | 查看当前分类下的条目（文档或文件），移动即预览                                                |
| `3`  | 详情 | 查看字段、编辑配置、查看文件路径或 Doctor 结果                                                |

视觉提示：

- 绿色边框 = 当前焦点面板；浅蓝底 = 当前选中行。
- **红色文字 = 缺失**（还没有真实文件或配置），**绿色文字 = 存在**；这只看「有没有」，不代表内容有效。
- 边框标题里有面板编号；列表右下角显示「当前位置 / 总数」。

终端尺寸影响布局：宽 ≥ 100 列且高 ≥ 24 行是左右双栏；60–99 列是上下单栏（焦点面板在上、预览在下）；再小则只提示空间不足、允许退出。调整窗口大小时，你的草稿、当前选择和滚动位置都会保留。

---

## 3. 日常操作流程

一个最典型的「改一项配置」流程是这样的：

1. **选分类**：在分类面板用 `j`/`k`（或 `↓`/`↑`）移动，`1` 键直达分类面板。
2. **进列表**：`Enter` 或 `Tab`/`2` 切到列表，用 `j`/`k` 选中一个条目。
3. **看详情**：`Enter` 进入详情（或 `3` 键）。移动选中项时详情会实时刷新。
4. **改字段**：在详情里按 `e` 进入当前字段开始输入（`Enter` 展开完整值）；输完 `Enter` 或 `Tab` 确认。
5. **保存**：按 `s`，或把光标移到详情最末的「保存」行按 `Enter`。成功后状态栏提示已保存，Doctor 可帮你检查完整性。
6. **退出**：按 `q`，正常退出。

按 `:` 打开设置弹层（语言 / 主题两行），`Enter`/`l` 换值立即生效并记住；`L` 直接切换 中文/English。

---

## 4. 键盘速查

| 按键                       | 作用                                                           |
| -------------------------- | -------------------------------------------------------------- |
| `j` / `k`，`↓` / `↑`       | 当前面板内下移 / 上移；移动立即刷新详情                        |
| `h` / `l`，`←` / `→`       | 在面板之间前移 / 后移                                          |
| `1` / `2` / `3`            | 直接聚焦 分类 / 列表 / 详情                                    |
| `Tab` / `Shift+Tab`        | 面板循环切换（Shift 反向）                                     |
| `Enter`                    | 逐层进入：分类 → 列表 → 详情 → 当前字段；详情最末行执行保存    |
| `Esc`                      | 关闭弹窗，或按 详情 → 列表 → 分类 回退；在分类面板上则请求退出 |
| `g g`（500ms 内两次）/ `G` | 跳到首项 / 末项                                                |
| `/`                        | 搜索文档路径（在分类面板上使用时先聚焦列表）                   |
| `s`                        | 保存当前草稿                                                   |
| `:` / `L`                  | 设置弹层 / 直接切换语言                                         |
| `a`                        | 新建配置（分类 / 列表焦点时）                                  |
| `r`                        | 重载：详情重载磁盘版本 / 列表刷新 / Doctor 重新检查            |
| `f`                        | 打开托管文件列表                                               |
| `D`                        | 删除选中的文件（列表焦点时，需确认）                           |
| `e`                        | 编辑聚焦字段（详情焦点时；`Enter` 展开完整值）                 |
| `?`                        | 打开当前上下文快捷键帮助                                       |
| `q`                        | 请求退出（会检查未保存改动）                                   |
| `Ctrl+c`                   | 有弹窗时关闭弹窗；否则请求退出                                 |

**输入文字时**（编辑字段、搜索、弹窗输入）：`j/k/h/l/q/?/g/G/` 等都按普通字符输入，方向键按文本编辑语义移动光标，不会触发导航或退出。`Esc` 撤销当前字段的本次改动并恢复原值。

## 5. 编辑与保存

- 进入一个字段后直接打字修改；敏感字段（密码、Token、私钥等）输入时遮蔽，已有值默认隐藏，离开详情即恢复隐藏。
- `Esc` 在编辑字段时撤销该字段本次输入，回到之前的值。
- 保存成功后才算写入磁盘；保存前切换面板、滚动、预览都不会打断你，但**改变分类、改变条目、改变搜索、或新建目标**时，如果还有未保存改动，会先弹出「保存 / 放弃 / 取消」询问（默认停在取消）。
  - **保存**：先写入磁盘，再继续你要做的跳转。
  - **放弃**：只丢弃当前这份草稿，继续跳转。
  - **取消**：留在原地，什么都不改。
- 取消或放弃都不会写盘；保存失败会保留你的草稿，不会丢。

---

## 6. 新建配置

在分类或列表面板按 `n`，按当前分类不同：

- **App / Assets**：直接打开对应文档（不存在则新建）让你填写。
- **Platforms**：先选平台（Android / iOS / HarmonyOS / Windows / macOS / 小程序），再选「身份 / 根配置」或「环境签名」；选环境签名时还要输入一个环境名。
- **Services / Environments / Store**：输入一个名称（单个、安全、不含路径分隔符的目录名）。

新建文档保存后即成为真实配置；新建前如果还有未保存改动，同样会先确认。

---

## 7. 文件管理（图标、证书、截图等）

- 在详情里对「文件」类型字段按 `Enter`，选择一种操作：
  - **复制到工作区**：选一个源文件（绝对路径），再选工作区内的目标位置，确认后复制；源文件不会被修改。
  - **引用外部文件**：保存一个只读的绝对路径引用，不复制、不随工作区迁移。
  - **移除引用**：只清掉这个字段的引用，**永不删除源文件**。
- 按 `f` 打开「托管文件」列表，查看工作区里实际存在的文件；详情面板预览其路径。
  - 对缺失的文件按 `Enter` 会询问源文件路径，确认后导入；导入后条目变绿。
  - 对真实文件按 `Enter` 打开对应配置；删除后条目恢复红色（示例说明仍在）。
- 在列表焦点按 `d` 删除选中文件，需确认（默认取消）；`app.json` 不可删除，会给出说明。删除只删这一个文件、不递归删目录、不可撤销。
- 复制文件是**独立的一次提交**：之后即使取消编辑，已经复制的文件也不会被撤销（界面会明确提示）。

---

## 8. Doctor 完整性检查

- 进入「Doctor」分类，或按 `r`，执行一次**只读**检查：字段是否齐全、引用的文件是否存在、配置是否一致、权限是否合理。
- 结果列表里 `Enter` 查看某一条的状态与路径；`r` 重新检查。
- 它只报告「缺失 / 存在 / 未检查」，不会替你创建、修复或删除任何东西。
- 注意：「文件存在」不等于「证书有效」；未启用的平台不会报缺失；缺少解析能力时显示「未检查」而不是「通过」。

---

## 9. 语言设置

- 进入分类末尾的「Settings / 设置」，`j`/`k` 选择「中文」或「English」，`Enter` 立即应用并保存，下次启动沿用。
- 切换语言会覆盖界面文案、字段标签、帮助、确认框、错误与诊断信息；你输入的内容、文件路径、配置键、平台标识和按键本身不会被翻译。
- 启动时的初始化询问也会使用你保存的语言；命令行的 `--help` 仍为英文。

---

## 10. 退出

- 按 `q`（或分类面板上的 `Esc`、`Ctrl+c`）请求退出。
- 如果有未保存改动，会先弹出「保存 / 放弃 / 取消」确认。
- 有操作正在执行时（保存、复制、删除等），退出会等它完成；提交中的操作不可中断。
- 正常退出会释放工作区锁、恢复终端状态。另一个实例已经打开同一工作区时，你无法进入可写状态。

---

## 安全提示（重要）

- 你的密码、Token、私钥以**明文**存在本地目录，界面只是遮蔽显示；这不是加密保险箱。备份、云同步软件、恶意进程或误提交到 Git 都可能泄露它们。
- 工作区数据目录会创建 `.gitignore`（忽略全部内容），但这不阻止强制提交，也不是安全边界。
- Doctor 和普通日志、错误摘要不会显示敏感值或完整配置；复制敏感信息只能由你显式触发。

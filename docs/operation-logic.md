# lazyapp 操作指南

## 启动

在项目目录运行 `lazyapp`，或传入项目绝对路径。数据保存在该项目的 `.lazyapp/`，不扫描父目录。

没有工作区时，先在普通终端询问是否创建；仅 `y` / `yes` 同意。空输入、No、EOF 不写文件，Ctrl+C 退出。初始化模板与目录结构不变，创建后直接进入界面。

`lazyapp tui /绝对路径/项目` 同时打开 TUI 和本地 Web；`lazyapp web /绝对路径/项目` 只启动 Web，默认端口 3210。TUI 内按 `W` 也可启动 Web。

## TUI 布局

左侧是四组独立导航，右侧 `[0]` 是共享详情／编辑区。顶部显示工作区，底部显示任务、保存结果、错误和快捷键。

| 编号 | 内容 | 使用方式 |
| --- | --- | --- |
| `1` | 应用与资源 | 直接选择应用信息或资源配置 |
| `2` | 平台 | 展开 Android、iOS、HarmonyOS 等，直接选择平台信息或签名配置 |
| `3` | 服务／环境／商店 | 用 `[` / `]` 切换页签，选择清单条目 |
| `4` | 托管文件／Doctor | 用 `[` / `]` 切换文件清单与只读诊断 |
| `0` | 详情 | 查看当前目标、编辑字段 |

焦点面板使用蓝色边框；文件／配置缺失显示红色，存在显示绿色。颜色只表示存在性，不表示证书或凭据有效。

宽度至少 100 列、高度至少 24 行时显示四组导航，焦点组获得更多空间。较小窗口只显示焦点导航组与详情；60–79 列时上下堆叠。小于 60×16 时提示空间不足，但仍可退出、操作已打开的确认框。调整尺寸保留草稿和选择。

## 编辑一份配置

1. 按 `1–4` 聚焦导航组，用 `j/k` 或上下方向键选择条目。平台节点用 Enter 或右方向展开。
2. 配置条目 Enter 直接进入右侧编辑器；也可按 `0` 返回当前编辑器。
3. `j/k` 选择字段，`e` 编辑；文件字段打开导入／外部引用／移除操作。
4. Enter 接受本次输入；Esc 恢复本次输入前的值。
5. `s` 保存，或移到最后的保存行按 Enter。只有保存成功才清除未保存状态。
6. Esc 返回上次导航组；`q` 请求退出。

切换焦点、展开平台树不会替换正在编辑的目标。选择其他条目、切换内容页签、提交搜索或新建目标时，未保存草稿会询问保存／放弃／取消，默认取消。失败保留草稿与版本，不静默覆盖磁盘改动。

## 常用按键

| 按键 | 作用 |
| --- | --- |
| `1–4` / `0` | 聚焦四个导航组／详情 |
| `Tab` / `Shift+Tab` | 循环焦点 |
| `j/k`、上下方向 | 移动当前清单或字段选择 |
| `h/l`、左右方向 | 平台树收起／展开，或进入／返回详情 |
| `[` / `]` | 切换当前组的内容页签 |
| `g` / `G` | 首项／末项 |
| `/` | 搜索焦点组的文档路径；Esc 恢复原过滤 |
| `a` | 在当前配置分组中新建 |
| `e` / `s` | 编辑字段／保存 |
| `y` | 显式复制当前字段值，不把值写入状态栏 |
| `f` / `D` | 打开托管文件组／确认删除当前文件 |
| `r` | 重载配置、刷新清单或重新运行 Doctor |
| `:` / `L` | 设置语言与主题／切换语言 |
| `?` / `q` | 帮助／请求退出 |

输入文字时，数字、括号及 `j/k/h/l/q/?/g/G/` 等都作为普通字符，不触发导航。设置只在偏好保存成功后生效。

## 文件与诊断

- 缺失配置 Enter 打开干净草稿，保存才创建真实文件，不复制 `.example` 内容。
- 缺失资源 Enter 询问源文件，确认后导入。文件导入是独立提交：放弃配置草稿不会撤销已导入的文件。
- 外部引用只读；移除引用不删除源文件。删除只针对一个内部文件，不递归删除目录；`app.json`、平台父节点、Doctor 结果不可作为文件删除。
- 删除、覆盖默认取消，提交前检查文件版本。真实文件删除后，原有说明示例仍保留。
- Doctor 只读，区分缺失、错误、警告、通过与未检查；文件存在不代表签名或发布就绪。

## Web

Web 使用同样的左侧四组导航：应用与资源、平台树、服务／环境／商店页签、文件／Doctor。右侧共用编辑区域，不再额外套一列分类清单。

- 表单按基本信息、文件引用、凭据分区；保存／重载／放弃栏吸底。
- `Ctrl/⌘+S` 保存当前配置，遵循必填校验；弹窗中不会触发后台保存。
- 选中项标示当前配置，详情标题给出平台、签名用途和路径。密码默认遮蔽。
- 窄屏通过「导航」按钮打开独立滚动抽屉；选择配置后收起并返回编辑区，关闭再打开保留长清单位置。Esc 先关闭最上层确认框，再关闭导航，背景不随抽屉滚动。
- 文件支持原始字节导入、图片预览、下载、覆盖和删除；不修改图片像素，不提供 OCR。外部引用不通过 HTTP 读取。
- TUI 和 Web 可同时打开；版本冲突保留草稿，需显式重载。重新加载也遵循保存／放弃／取消。
- 只有右侧内容区进行页面滚动；侧栏和超过 100 项的长清单在明确边界内局部滚动。长清单可用方向键、PageUp／PageDown、Home／End 浏览，输入框保留原生按键行为。
- 返回文件／Doctor 恢复浏览位置；刷新、保存或失败保留上下文。底部状态栏显示操作反馈，不把内容顶下去；长反馈可聚焦后滚动查看。
- 内容区滚动超过 400px 后可使用右下角「顶部」按钮；系统开启减少动画时直接定位，不播放平滑滚动。

## 安全与退出

密码、Token 等可明文存放在本机，界面遮蔽不等于加密。工作区 `.gitignore` 不代替访问控制。日志与诊断不输出秘密值。

正常退出释放操作资源并恢复终端；提交中的写操作等待完成。多个界面可同时打开工作区，实际提交时独占加锁；过期版本和遗留锁拒绝写入，不自动抢锁。
